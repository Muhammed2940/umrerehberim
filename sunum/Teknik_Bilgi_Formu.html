3. System architecture

ClientFlutter (Dart), a single codebase for Android and iOS; ~244 source files, ~58,000 lines of code; ~2,000 interface texts per language
AuthenticationFirebase Authentication (managed identity, per-user accounts)
Primary databaseCloud Firestore (document DB). Collections include users, agencies, trips, hotels, rooms, shops, shop_transactions, coupons, settlements, audit_logs, risk_reviews, agency_messages, platform_settings
Real-time locationFirebase Realtime Database: locations/{agency}/{user} with latitude, longitude, accuracy, timestamp
NotificationsFirebase Cloud Messaging, topic-based per agency and per trip
Live audio (radio)WebRTC via LiveKit cloud SFU; one-to-many broadcast with background playback
Maps & sensorsOpenStreetMap tiles, device GPS (high accuracy, background), compass with magnetic declination correction
ContentQuran text: Tanzil Uthmani (CC BY 3.0); Amiri Quran font (OFL); recitation audio and translations from public Quran services; exchange rates from public finance APIs
Offline capabilityLocal cache of user, trip, hotel, room, prayer times, exchange rates and notifications
Current hosting regionGoogle Cloud (Firestore nam5, RTDB us-central1); planned migration to a Saudi-hosted region or sovereign cloud for production

4. Security & data protection

Access controlServer-side security rules on every collection; role read from the user record; agencies are isolated from each other
ConsentMandatory privacy notice and consent before first use; location sharing is opt-in and can be turned off
Data minimisationNational ID masked in the interface; location visible only to the user's own agency
TraceabilityAudit log of sensitive actions (actor, action, time); rule-based fraud alarms with review states
SecretsKeys and signing material kept outside source control
EncryptionTLS in transit; provider-managed encryption at rest
Compliance roadmapSaudi PDPL alignment, NCA-aligned controls, independent penetration test, server-side token service for radio, backups and disaster recovery
